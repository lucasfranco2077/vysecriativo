# VYSE. — Vídeo Marketing & Performance

Site institucional da VYSE com apresentação dos serviços, planos e contato comercial.

## Prévia local

Abra `index.html` no navegador. O site usa HTML, CSS e JavaScript e não precisa de instalação ou compilação.

## Arquivos

- `index.html`: conteúdo e estrutura da página.
- `style.css`: identidade visual e adaptação para celular.
- `app.js`: links de WhatsApp com mensagem por serviço e atualização do ano.
- `assets/`: materiais visuais da VYSE.
